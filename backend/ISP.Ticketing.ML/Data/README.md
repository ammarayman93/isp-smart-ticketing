# ISP Ticket Dataset — Phase 4.1

This dataset is a **curated synthetic/seed dataset** created for the graduation-project prototype. It is not presented as production customer data.

- Rows: 180
- Categories: 6
- Rows per category: 30
- Languages: Arabic and English
- Fields: Text, Category, Priority, Team
- Intended use: initial ML.NET category-classification training and evaluation.

Categories:
- Service Outage
- Slow Speed
- Router Issues
- WiFi Problems
- Billing
- Other

The dataset is deliberately balanced so the first evaluation is not dominated by one class. For the final project evaluation, it should be replaced or augmented with anonymized real ISP tickets when available.
